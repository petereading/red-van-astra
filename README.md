# 紅Van — Red Van: Fast and Furious

香港市區風格的原創 3D 街機駕駛遊戲。玩家駕駛紅頂小巴，在 **180 秒**內由深水埗出發，沿虛構路線抵達旺角總站，途中停車開門接送乘客。

## 第一版功能

- 主畫面、玩法說明、音量／畫質設定及暫停；可選「挑戰模式」或「暢玩模式」。
- 挑戰模式提供實時 S／A／B／C／D 評級、下一級所需分數及結算；暢玩模式不計分，只判定是否準時完成全部指定接送。
- 1.42 公里路線、第三身追蹤鏡頭、轉向箭嘴，沒有小地圖。
- 每局十名乘客，隨機上客位置及下游落客安排；十六座容量。
- 車門動畫、招手及上下車動畫、投幣音效；以左前車門是否在方塊內判定停站，無需整架小巴精確對正。
- 左側行車、隨機車流、行人、圍欄、燈柱、橙色垃圾桶、商店招牌。
- Rapier 實體碰撞、卡車復位；挑戰模式有車輛損壞及車況歸零失敗，暢玩模式不因車損結束或因復位扣時。
- 三處交通燈，黃燈預告後紅燈約五秒；行人過路，其他車輛會停燈及保持車距。交通駛出路線兩端後安全循環，不會堆在總站。
- 行人遇險會及時跳開並站穩，沒有流血或受傷畫面；挑戰模式照常扣分，候車乘客仍可上車。
- 超過 80 km/h 的車速顯示及警示聲；超速與危險車門操作扣分。
- 街機式快速煞停：80 km/h 可在約 0.7 秒內停下；有乘客時高速急煞會引起不滿，挑戰模式扣分。
- 小巴及車輛圓潤外殼、輪圈、門框、冷氣及車身細節；路面與樓宇材質、24 種商店招牌、不同樓高、簷篷、露台及冷氣機。
- 原創 158 BPM 電子音樂、引擎、剎車、碰撞及預製粵語合成短句。
- 最高紀錄及設定保存在本機；基本觸控方向及油門／剎車按鈕。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| W / ↑ | 油門 |
| S / ↓ | 快速剎車；停妥後放開再按才倒車 |
| A / D 或 ← / → | 左右轉向 |
| Space | 手掣 |
| E | 開門／關門 |
| H | 響號 |
| R | 返回最近安全路面；挑戰模式扣 5 秒及 30 駕駛分 |
| Esc | 暫停／繼續 |

綠色方塊代表上客，藍色代表有乘客要求落車，黃色為尾站。將左前車門停在發光方塊內，車速低於 1.8 km/h 即可按 E 開門。乘客逐一上下車後，再按 E 關門行車。抵達尾站後，須完成落客及關門才能完成路線。暢玩模式須接載並送達全部十名乘客，而且沒有錯過指定落客，才算任務成功。

## 本機啟動

需要 Node.js 22.12+（或 24 LTS）。

```sh
npm ci
npm run dev
```

開啟 Vite 顯示的本機網址。遊戲需要 WebGL 2；建議先用電腦瀏覽器和鍵盤。所有音樂、字體及音效隨遊戲打包，不需要 API 金鑰、登入或遊戲後端。

```sh
npm run build
npm run preview
```

`dist/` 可部署至支援靜態檔案的主機。專案同時包含 Sites 的靜態發布設定；GitHub 儲存庫維持使用者設定的存取權限。

## 驗證

```sh
npm test
npm run test:drive -- 8521986 42 12345
```

`test:drive` 在無瀏覽器繪圖的環境中，執行真正的 `Game.step`、Rapier 碰撞、交通及乘客系統。測試車手透過油門、轉向、剎車及車門操作走完全程，路線測試中不會瞬移。它不代替實機畫面、音效聆聽或手機效能驗證。

開發伺服器的 `?qa=1` 提供可見的測試控制，包括完整路線駕駛、停站、超速、逾時及碰撞場景。正式建置不會啟用測試面板。

更多驗證結果及限制見 [TESTING.md](TESTING.md)，街景來源和素材說明見 [ASSETS.md](ASSETS.md)。

## 架構

| 檔案 | 職責 |
| --- | --- |
| `src/core.ts` | 路線、隨機乘客、停車判定、駕駛與評分規則 |
| `src/game.ts` | 遊戲狀態、乘客、交通、輸入、鏡頭、HUD |
| `src/physics.ts` | Rapier 車輛與物件碰撞 |
| `src/visuals.ts` | 原創小巴、街景、人物及停車方塊 |
| `src/surfaces.ts` | 路面、地磚、灰泥及外牆貼圖材質 |
| `src/traffic.ts` | 交通燈時序、車距、總站出口及車流循環 |
| `src/audio.ts` | 原創音序、合成音效及粵語音檔播放 |
| `src/ui.ts`、`src/style.css` | 主畫面、遊戲介面、設定及結算 |

本作以 Crazy Taxi 的街機節奏為靈感，與 SEGA 沒有關聯，也未使用其程式、角色、關卡、音樂或美術素材。


## 自動示範＋錄影

主畫面新增「自動示範＋錄影」。請在電腦版 Chrome／Edge 開啟已發布的遊戲：

1. 可先在「聲音及畫質」調整音量及畫質，再按「自動示範＋錄影」。
2. 按「選擇遊戲分頁並錄影」，在瀏覽器分享視窗選擇目前的《紅Van》分頁。不要選其他分頁、整個螢幕或視窗。不需要分享系統聲音或咪高峰。
3. 主畫面錄製 5 秒後自動開始倒數及駕駛。保持分頁在前景；切換分頁或失焦會暫停，返回後按「繼續駕駛」。
4. 正常速度跑完整條限時 180 秒的路線，提早到站即計分。計分畫面保留 8 秒後自動停止。
5. 在影片視窗預覽，再按「下載影片」。格式按瀏覽器支援選用 WebM 或 MP4。關閉視窗後，可按「查看／下載錄影」重新開啟。

畫面全程標示「自動駕駛示範」，不計入個人最佳。示範使用固定路況 `8521986`；使用正式駕駛物理、油門／轉向／車門操作、交通及碰撞，沒有瞬移、延長時限或修改分數。自動車手可能碰撞，結果照常扣分。

錄製來源是使用者選擇的瀏覽器分頁（包含 DOM 主畫面、HUD 及計分畫面），聲音直接來自遊戲的 Web Audio 混音。沒有咪高峰或系統聲音輸入，也不會上載影片。音檔未載入時，錄影使用可收錄的合成替代音效，而非瀏覽器外部語音。

可隨時按「停止並保存」或停止分享，下載已錄下的片段。影片只暫存於本頁；請在重新載入、離開或開始另一段錄影前下載。錄影設有 160 MB／10 分鐘保護上限。瀏覽器不提供錄影 API 時會顯示說明；macOS 如拒絕螢幕錄影，需由使用者在系統權限設定允許瀏覽器。

本次環境的雲端瀏覽器停用了 WebGL，無法完成真實 3D 畫面錄影及音效聆聽驗證。已另外檢查實際選單、HUD 及結算介面；錄影 API 的生命週期測試使用模擬物件，並非實際編碼的影片驗證。
