# 紅Van — Red Van: Fast and Furious

香港市區風格的原創 3D 街機駕駛遊戲。玩家駕駛紅頂小巴，在 **180 秒**內由深水埗出發，沿虛構路線抵達旺角總站，途中停車開門接送乘客。

## 第一版功能

- 主畫面、玩法說明、音量／畫質設定、暫停及 S–D 評級結算。
- 1.42 公里路線、第三身追蹤鏡頭、轉向箭嘴，沒有小地圖。
- 每局十名乘客，隨機上客位置及下游落客安排；十六座容量。
- 車門動畫、招手及上下車動畫、投幣音效。
- 左側行車、隨機車流、行人、圍欄、燈柱、橙色垃圾桶、商店招牌。
- Rapier 實體碰撞、車輛損壞、車況歸零結束、卡車復位。
- 超過 80 km/h 的車速顯示及警示聲；超速與危險車門操作扣分。
- 原創 158 BPM 電子音樂、引擎、剎車、碰撞及預製粵語合成短句。
- 最高紀錄及設定保存在本機；基本觸控方向及油門／剎車按鈕。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| W / ↑ | 油門 |
| S / ↓ | 剎車，停下後倒車 |
| A / D 或 ← / → | 左右轉向 |
| Space | 手掣 |
| E | 開門／關門 |
| H | 響號 |
| R | 返回最近安全路面，扣 5 秒及 30 駕駛分 |
| Esc | 暫停／繼續 |

綠色方塊代表上客，藍色代表有乘客要求落車，黃色為尾站。整架車須停妥並對準方塊，按 E 開門。乘客逐一上下車後，再按 E 關門行車。抵達尾站後，須完成落客及關門才能完成路線。

## 本機啟動

需要 Node.js 22.12+（或 24 LTS）。

```sh
npm ci
npm run dev
```

開啟 Vite 顯示的本機網址。遊戲需要 WebGL 2；建議先用電腦瀏覽器和鍵盤。所有音樂、字體及音效隨遊戲打包，不需要 API 金鑰、登入或遊戲後端。

```sh
npm run build
npm run preview
```

`dist/` 可部署至支援靜態檔案的主機。專案同時包含 Sites 的靜態發布設定；GitHub 儲存庫維持使用者設定的存取權限。

## 驗證

```sh
npm test
npm run test:drive -- 8521986 42 12345
```

`test:drive` 在無瀏覽器繪圖的環境中，執行真正的 `Game.step`、Rapier 碰撞、交通及乘客系統。測試車手透過油門、轉向、剎車及車門操作走完全程，路線測試中不會瞬移。它不代替實機畫面、音效聆聽或手機效能驗證。

開發伺服器的 `?qa=1` 提供可見的測試控制，包括完整路線駕駛、停站、超速、逾時及碰撞場景。正式建置不會啟用測試面板。

更多驗證結果及限制見 [TESTING.md](TESTING.md)，街景來源和素材說明見 [ASSETS.md](ASSETS.md)。

## 架構

| 檔案 | 職責 |
| --- | --- |
| `src/core.ts` | 路線、隨機乘客、停車判定、駕駛與評分規則 |
| `src/game.ts` | 遊戲狀態、乘客、交通、輸入、鏡頭、HUD |
| `src/physics.ts` | Rapier 車輛與物件碰撞 |
| `src/visuals.ts` | 原創小巴、街景、人物及停車方塊 |
| `src/audio.ts` | 原創音序、合成音效及粵語音檔播放 |
| `src/ui.ts`、`src/style.css` | 主畫面、遊戲介面、設定及結算 |

本作以 Crazy Taxi 的街機節奏為靈感，與 SEGA 沒有關聯，也未使用其程式、角色、關卡、音樂或美術素材。
